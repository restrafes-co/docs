description: "Get an individual access point and its operational configuration through the Consumer API."

openapi: "/openapi/consumer-access-points.json GET /api/consumer/v1/access-points/{id}"

The response contains the stored access point and its operational configuration. `createdAt` and `updatedAt` are UTC ISO 8601 timestamps.
