---
title: "Remove access-point permissions"
description: "Remove selected access groups and identities from an access point."
icon: "key-square"
openapi: "/openapi/consumer-access-points.json DELETE /api/consumer/v1/access-points/{id}/permissions"
playground: "interactive"
---

## Behavior

- Supply at least one access-group ID or identity ID.
- Grants omitted from the request remain unchanged.
- Removing an ID that is not currently granted does not change other grants.
- The response contains the complete direct permission state after the update.
