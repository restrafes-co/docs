---
title: "Add access-point permissions"
description: "Add access groups and identities to an access point without replacing existing grants."
icon: "key-round"
openapi: "/openapi/consumer-access-points.json POST /api/consumer/v1/access-points/{id}/permissions"
playground: "interactive"
---

## Behavior

- Supply at least one access-group ID or identity ID.
- Grants omitted from the request remain unchanged.
- Adding an already granted ID does not create a duplicate.
- Every supplied ID must belong to the access point’s organization.
- The response contains the complete direct permission state after the update.

An unknown ID or an ID from another organization returns `400`:

```json
{
  "error": "One or more permissions do not belong to this organization"
}
```
