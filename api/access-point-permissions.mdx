---
title: "List access-point permissions"
description: "List access groups and identities granted direct access to an access point."
icon: "list"
openapi: "/openapi/consumer-access-points.json GET /api/consumer/v1/access-points/{id}/permissions"
playground: "interactive"
---

Access groups are ordered by name in ascending order. Identities are ordered by creation time in ascending order. Neither list is paginated.

## Identity values

| Field | Values |
| --- | --- |
| `type` | `USER`, `ROBLOX`, `ROBLOX_GROUP`, `CARD`, or `PIN` |
| `status` | `NOT_INVITED`, `INVITED`, `PSUEDO`, `PRESENT`, `LEFT`, `REVOKED`, or `SUSPENDED` |

`user` is present only when the identity is linked to an XCS user. It contains `username` and `displayName`.
