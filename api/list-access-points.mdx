---
title: "List access points in a location"
description: "List every access point in a location through the Consumer API."
icon: "list"
openapi: "/openapi/consumer-access-points.json GET /api/consumer/v1/locations/{id}/access-points"
playground: "interactive"
---

Results are ordered by access-point name in ascending order, then by ID. The list is not paginated.

A location with no access points returns:

```json
{
  "accessPoints": []
}
```
