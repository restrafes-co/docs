## Authentication

Set `X-API-Key` to an organization API key. The key must belong to the location's organization and include the location when the key has location restrictions.

## Path parameter

<ParamField path="id" type="string" required>
  Location ID.
</ParamField>

## Response

A successful request returns `200` with every access point in the location and each access point's operational configuration. Results are ordered by name in ascending order, then by ID. The list is not paginated.

## Example request

```bash
curl \
  "https://api.restrafes.co/api/consumer/v1/locations/598f41c2-b931-4819-89b7-555d5371314a/access-points" \
  -H "X-API-Key: $XCS_API_KEY"
```

## Errors

| Status | Cause                                                                           | Recovery                               |
| ------ | ------------------------------------------------------------------------------- | -------------------------------------- |
| `401`  | `X-API-Key` is missing or invalid, or the organization is inactive or archived. | Send an active organization API key.   |
| `403`  | The key belongs to another organization or excludes the requested location.     | Use a key authorized for the location. |
| `404`  | No location has the supplied `id`.                                              | Check the location ID.                 |
