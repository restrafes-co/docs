## Base URL

```
https://api.restrafes.co/api/consumer/v1
```

## Authentication

Send the organization API key in the `X-API-Key` header:

```bash
curl \
  -H "X-API-Key: $XCS_API_KEY" \
  https://api.restrafes.co/api/consumer/v1/ping
```

The access-point endpoints require this header. The API returns `401` when the key is missing, unknown, belongs to an inactive organization, or belongs to an archived organization.

An organization API key may be restricted to selected locations. A location-scoped key receives `403` when it targets an access point outside those locations. A key without location restrictions may target any access point owned by its organization.

Store API keys in server-side secret storage. Do not include them in Roblox `LocalScript` code, browser code, source control, logs, or client-visible configuration.

## Endpoints

| Method   | Path                                                                      | Operation                                         |
| -------- | ------------------------------------------------------------------------- | ------------------------------------------------- |
| `GET`    | `/`                                                                       | Check whether the Consumer API is reachable       |
| `GET`    | `/ping`                                                                   | Read the current Consumer API version             |
| `GET`    | [`/locations/{id}/access-points`](/api/list-access-points)                | List every access point in a location             |
| `GET`    | [`/access-points/{id}`](/api/get-access-point)                            | Get an individual access point                    |
| `PATCH`  | [`/access-points/{id}`](/api/access-points)                               | Partially update an access point                  |
| `GET`    | [`/access-points/{id}/permissions`](/api/access-point-permissions)        | List directly granted permissions                 |
| `POST`   | [`/access-points/{id}/permissions`](/api/add-access-point-permissions)    | Add permissions without replacing existing grants |
| `DELETE` | [`/access-points/{id}/permissions`](/api/remove-access-point-permissions) | Remove selected permissions                       |
| `POST`   | [`/access-points/{id}/remote-unlock`](/api/remote-unlock)                 | Send a remote-unlock command                      |

## Service check

`GET /` does not require authentication.

```bash
curl https://api.restrafes.co/api/consumer/v1/
```

```json
{
  "message": "ok"
}
```

## Version

`GET /ping` does not require authentication.

```bash
curl https://api.restrafes.co/api/consumer/v1/ping
```

```json
{
  "success": true,
  "version": "2.0.0"
}
```

## Error format

Endpoint errors return a JSON object with an `error` string:

```json
{
  "error": "API key not authorized for this access point"
}
```

Some configuration errors include a machine-readable `code`.
