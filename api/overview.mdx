XCS provides a REST API for programmatic access-control integrations and a server-side Roblox API for in-experience devices. The Consumer API v1 manages access-point settings, direct grants, and remote-unlock commands.

## Consumer API authentication

Consumer API access-point endpoints use API key authentication. Pass the organization API key in the `X-API-Key` header:

```bash
curl -H "X-API-Key: $XCS_API_KEY" \
  https://api.restrafes.co/api/consumer/v1/access-points/76094322-c72f-4aca-bb25-4c2dc2964e37/permissions
```

<Callout type="warning">
  Use the `X-API-Key` header, not the `Authorization: Bearer` header. The
  platform API (v3 routes) uses session-based authentication via browser
  cookies.
</Callout>

## Consumer API base URL

```
https://api.restrafes.co/api/consumer/v1
```

All Consumer API endpoints are relative to this base URL.

## API Key Management

Create and revoke organization API keys from the organization management page in the XCS dashboard.
