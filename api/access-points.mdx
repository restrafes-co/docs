## Update behavior

- Include at least one supported top-level field.
- If `configuration` is present, include at least one configuration field.
- Omitted fields remain unchanged.
- `null` is accepted only for `description` and `configuration.armedScheduleId`.
- Names are trimmed and must be unique within the location, using a case-insensitive comparison.
- An armed schedule must belong to the same organization. It must apply to all organization locations or to the access point’s location.

The configured `unlockTime` may be any non-negative number. When remote unlock uses that value, XCS constrains the applied duration to 2–60 seconds. A duration supplied directly to a remote-unlock request takes precedence.

## Duplicate names

A name conflict returns `409`:

```json
{
  "error": "An access point named \"North entrance\" already exists in this location."
}
```
