## Authentication

Set `X-API-Key` to an organization API key. The key must belong to the access point's organization and include the access point's location when the key has location restrictions.

## Path parameter

<ParamField path="id" type="string" required>
  Access-point ID.
</ParamField>

## Request body

All fields are optional, but the body must contain at least one supported top-level field. If `configuration` is present, it must contain at least one supported configuration field.

| Field                           | Type             | Accepted values or behavior                                                                                         |
| ------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| `name`                          | string           | Non-empty after trimming. The trimmed name must be unique within the location, using a case-insensitive comparison. |
| `description`                   | string or `null` | `null` clears the description. An empty string is stored as an empty string.                                        |
| `type`                          | string           | `REGULAR` or `ELEVATOR`.                                                                                            |
| `configuration.active`          | boolean          | Enables or disables the access point.                                                                               |
| `configuration.armed`           | string           | `ARMED`, `DISARMED`, or `AUTO`.                                                                                     |
| `configuration.armedScheduleId` | string or `null` | Schedule ID, or `null` to remove the armed schedule.                                                                |
| `configuration.offlineMode`     | string           | `LOCKED` or `UNLOCKED`.                                                                                             |
| `configuration.unlockTime`      | number           | Configured unlock duration in seconds. Must be finite and greater than or equal to `0`.                             |

Omitted fields remain unchanged. `null` is accepted only for `description` and `configuration.armedScheduleId`.

An armed schedule must belong to the same organization. It must either apply to all organization locations or belong to the access point's location.

When remote unlock uses the configured `unlockTime`, the remote-unlock operation constrains the applied duration to 2–60 seconds. A duration supplied directly to the remote-unlock request takes precedence over this configured value.

## Example request

```bash
curl -X PATCH \
  "https://api.restrafes.co/api/consumer/v1/access-points/76094322-c72f-4aca-bb25-4c2dc2964e37" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $XCS_API_KEY" \
  --data '{
    "name": "North entrance",
    "description": "Public lobby doors",
    "configuration": {
      "active": false,
      "armed": "AUTO",
      "armedScheduleId": "1cdb12d5-7620-4fb0-bef5-7d781f504aae",
      "offlineMode": "UNLOCKED",
      "unlockTime": 12
    }
  }'
```

## Errors

| Status | Cause                                                                                                                                                       | Recovery                                                                              |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `400`  | The body or `configuration` object is empty, `name` or `armedScheduleId` contains only whitespace, or the armed schedule is not available to this location. | Send at least one supported field and correct the value named by the `error` message. |
| `401`  | `X-API-Key` is missing or invalid, or the organization is inactive or archived.                                                                             | Send an active organization API key.                                                  |
| `403`  | The key belongs to another organization or excludes the access point's location.                                                                            | Use a key authorized for the access point's location.                                 |
| `404`  | No access point has the supplied `id`.                                                                                                                      | Check the access-point ID.                                                            |
| `409`  | Another access point in the location has the requested name.                                                                                                | Use a name that is unique within the location.                                        |
| `422`  | The JSON body does not match the request schema, including unknown fields, missing bodies, or incorrect JSON types.                                         | Correct the body shape and field types.                                               |

Example duplicate-name response:

```json
{
  "error": "An access point named \"North entrance\" already exists in this location."
}
```
