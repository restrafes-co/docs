This guide gives you the shortest path to a configured access point in the XCS dashboard. Roblox integration and remote unlock are optional next steps.

## Prerequisites

- A verified XCS account

If you do not have an account yet, start with [Creating an Account](/guides/creating-an-account). You must be able to create an organization or administer an existing one.

<Steps>
  <Step title="Create or open your organization">
    Log in to [the XCS dashboard](https://xcs.restrafes.co). Create an organization if prompted, or select an organization where you are an Owner or Admin.
  </Step>
  <Step title="Create a location">
    Open **Locations**, select **Create Location**, and enter a name. Roblox credentials are not required unless you plan to use remote unlock.
  </Step>
  <Step title="Create an access point">
    Open the location, go to **Access Points**, and select **Create Access Point**. Enter a name such as “Main Gate.”
  </Step>
  <Step title="Assign access">
    Add an access group or a specific identity, then save the access point.
  </Step>
  <Step title="Verify the result">
    Return to the location’s **Access Points** list and confirm that the access point appears with the access assignments you saved.
  </Step>
</Steps>
