Use the dashboard navigation to open the resource you want to manage. Available actions depend on your organization role.

| Task | Where to go |
| --- | --- |
| Manage members or organization settings | Select an organization, then open its member or settings area |
| Create or manage a location | Select an organization, then open **Locations** |
| Create or manage an access point | Open a location, then select **Access Points** |
| Create or revoke an API key | Open the organization’s API-key management area |
| Link a Roblox or Discord account | Open your profile, then select **Settings > Accounts** |

<Callout type="info">
  If an action is unavailable, ask an organization Owner or Admin to confirm your role.
</Callout>
