Start with the supplied Hera model. It includes the server loader, `CONFIGURATION`, `CAR`, and `FLOORS`. Place the model in `Workspace` and move the car and landings together when positioning it.

## Set up floors and entrances

Each landing under `FLOORS` has an integer name and a `LEVEL_MAIN` part. The car stops when the center Y of `CAR/.PLATFORM` matches the landing's `LEVEL_MAIN` center Y.

Door groups pair the car's entrances with the landings they serve. A group must exist under `.DOORS` on both the car and the landing. By default, `F` maps to group `1` and `R` maps to group `2`.

For example, a car button named `F2` calls floor `2` using the front entrance. A front hall Up button at that floor uses `.BUTTONS/F/U/BUTTON`. Fixture names use floor numbers, even when you configure a different display label.

See [Model structure](/hera/model-structure) for the required parts and [Buttons and lights](/hera/configuration/buttons) for fixture names.

## Run and customize the elevator

Start Play and use a hall button or a car button to call the elevator. If it fails to start, check the first Hera error in server Output. A server integration should [wait for a state response](/hera/integration/controller-api#connect-and-wait-for-startup) before issuing commands.

To fit the elevator to your building, [add floors or entrances](/hera/adding-floors), then adjust motion, doors, fixtures, and service modes in [Configuration](/hera/configuration/overview).
