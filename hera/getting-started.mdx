Commission the supplied layout before moving landings or changing `CONFIGURATION`. Use a complete model with its server loader and two landings that share an entrance.

## Place the elevator

1. Insert the complete model into `Workspace` in Edit mode. Move the car and landings together if you need to reposition the installation.
2. Verify the elevator root contains the supplied loader, `CONFIGURATION`, `CAR` and `FLOORS`. The [model tree](/hera/model-structure) shows the required references and fixture names.
3. At the intended startup landing, align the center Y of `CAR/.PLATFORM` with `LEVEL_MAIN`. Confirm that the car and both test landings have matching numeric groups under `.DOORS`.

## Call, ride and return

Start **Play** with an avatar and open server **Output**. Register a hall call, then a car call to the second landing. Verify that the car levels, the selected entrance opens and the call lamps clear. Run the return trip in the opposite direction. During a normal close, step into the sensor field and verify reopening.

If the car fails to start, diagnose the first Hera error in server Output. A server integration should [wait for a state response](/hera/integration/controller-api#connect-and-wait-for-startup) before issuing commands.

## Fit the model to the building

Stop Play before editing. [Add landings or entrances](/hera/adding-floors), [tune the configuration](/hera/configuration/overview), then run the [commissioning checks](/hera/testing) for the equipment you changed.
