Run the applicable checks in **Play** with an avatar and server **Output** open. Record the active service mode, floor, door group and call direction for any failure.

## Normal travel and fixtures

| Test | Expected result |
| --- | --- |
| Shortest run, longest run and a return run | The car levels at `LEVEL_MAIN`, the selected entrance opens and the call lamp clears. |
| Compatible and opposing hall calls ahead of a running car | The car answers a compatible call if it can brake in time. An opposing call can remain for the return sweep. |
| Each COP destination and hall direction | The intended floor and entrance receive the call. PI labels, lantern direction and audio cues match their configured events. |
| Idle away from the parking landing | The car parks with its doors closed if parking is enabled. |
| Ride from different positions on the platform | Passenger welding carries and releases the avatar at the configured phase. |

## Doors and sensors

| Test | Expected result |
| --- | --- |
| Front and rear calls on a multi-entrance car | Only the requested group opens. A call to a missing group is rejected. |
| Obstruction during a normal close | The obstructed group reopens and uses its reopen dwell. |
| Door Hold followed by Door Close | The selected group holds open, then the hold releases. |
| Obstruction through the nudge timeout | With the warning enabled, it sounds before the nudge close. |
| Scripted call with `accessibility = true` | The entrance uses the configured extended dwell and nudge timeout. |

## Special service

- **Fire service:** Test both recall landings and recall during motion. Enter Phase II after recall. Verify full and early-release strokes on Door Close and Door Open. Return to Phase I, complete recall, then reset. [Fire service](/hera/operation/fire-service)
- **Independent:** Hold a destination through full closure. Repeat and release during closing to verify reversal. Register a hall call during independent service, then clear independent while stationary and register a fresh hall call. [Independent service](/hera/operation/independent-service)

## Extensions and integrations

- **Floor lockouts:** Try a fresh call before, during and after a lock. Test the other entrance and overlapping locks when applicable. [Floor lockouts](/hera/extensions/floor-lockouts)
- **ERSA:** Test an intermediate station with every car available, then with one car in special service. Cancel an assigned call while another eligible car is available and observe reassignment. [Group control](/hera/integration/group-control-and-displays#ersa-group-control)
- **XCS:** In a published running server, select its job ID, verify a fresh state report and check a remote command against the car's local state. [XCS](/hera/integration/xcs)

Use the [troubleshooting reference](/hera/reference/troubleshooting) to trace a failed check.
