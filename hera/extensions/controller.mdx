Hera passes a per-car controller to `init(controller)` and `event(name, data, controller)`. Use dot calls such as `controller.door.open(1)`.

## Elevator

| Member | Returns |
| --- | --- |
| `controller.elevator.model` | The Roblox model containing this extension's `extensions` folder. |
| `controller.elevator.getState()` | A copy of the current state, including `floor`, `trueFloor`, `operating`, `service` and `queue`. |

Use `door.getState` for an entrance's state. The [state reference](/hera/reference/events) describes the movement and service fields.

## Doors

| Method on `controller.door` | Behavior |
| --- | --- |
| `groups(floor?)` | Sorted numeric groups present in both the car and the selected landing. Defaults to the tracked current floor. |
| `open(group?)` | Requests opening at the current landing. Omitting the group tries all groups. |
| `close(group?)` | Requests closing at the current landing. Omitting the group tries all groups. |
| `getState(group)` | The group's current state string, or `nil` for an unknown group. |
| `onChanged(listener)` | Subscribes to `onDoorStateChanged`. The listener receives its data. |

Door commands return `true` when at least one group accepts the request. Manual commands require an active, stationary elevator in normal service. Hera checks landing alignment and entrance availability, skips nudging groups on open, and skips obstructed groups on close.

## Floors

| Method on `controller.floor` | Behavior |
| --- | --- |
| `list()` | A copy of the served floor numbers, ordered from lowest landing to highest. |
| `current()` | The controller's tracked floor (`trueFloor`). The car can still be moving. |
| `lock(floor, scope?)` | Acquires one rule and returns its release function. An unknown floor, unavailable entrance or invalid scope raises an error. |
| `isLocked(floor, scope?)` | Checks registered extension rules for a match against the supplied fields. |
| `onChanged(listener)` | Subscribes to `onFloorChanged`. The payload contains `floor` and can include `label`. |

A lock scope accepts `doorGroup`, `source` and `direction`. Sources are `"car"`, `"landing"`, `"api"` and `"parking"`. Directions are `-1`, `0` and `1`. An omitted field on a rule matches any value. [Lockout examples and release behavior](/hera/extensions/floor-lockouts)

## Calls

| Method on `controller.call` | Behavior |
| --- | --- |
| `add(floor, options?)` | Registers a call and returns a result table. |
| `cancel(floor, direction, doorGroup)` | Returns a result table for cancellation of the matching queue entry. A moving car can finish braking before removal. While Phase I is active, returns `fire_service_active`. |
| `onChanged(listener)` | Subscribes to `onQueueChanged`. Read `data.queue` for the updated queue. |

`add` defaults to source `"api"` and computes direction from the tracked floor to the destination. If you omit `doorGroup`, Hera selects the lowest available group that the call may use. Pass an explicit group when the caller needs a particular entrance.

```lua
local result = controller.call.add(2, {
    source = "landing",
    direction = 1,
    doorGroup = 1,
    accessibility = true,
})
if not result.success then
    warn("Call rejected", result.reason)
end
```

Call sources are `"api"`, `"car"` and `"landing"`. Pass `accessibility = true` for extended door timers. A duplicate returns `success = true` and `duplicate = true`. Rejections include `floor_locked`, `invalid_floor`, `invalid_door_group` and service-specific reasons. Use the door event for the group's fully open state.

## Events

`controller.events.on(name, listener)` subscribes to any named Hera event. The filtered listener and the three `onChanged` methods each receive a copy of the data and return an unsubscribe function. The module-level `extension.event` receives the name, copied data and controller automatically. Registering both callbacks for the same event invokes both.

API request packets and per-call acknowledgement messages do not go to `extension.event`. An error in this hook is reported with the extension and event names. Subsequent events can still be delivered. [Event names and payloads](/hera/reference/events)
