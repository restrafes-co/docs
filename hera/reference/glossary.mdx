title: "Hera terminology"
description: "Hera-specific identifiers and conventions used in the model and controller API."
icon: "book-open-text"
---

| Term | Meaning in Hera |
| --- | --- |
| Floor number | Integer model name under `FLOORS`, used by calls and configuration lookups. |
| Floor label | Display text from `API.FLOOR_LABELS`, such as `L` for floor `1`. |
| Door group | Numeric ID pairing car and landing assemblies. The ID must exist on both sides of the entrance. |
| Door alias | Fixture-name prefix mapped to a door group. Defaults are `F = 1` and `R = 2`. |
| `LEVEL_MAIN` | Landing datum matched to the center Y of `CAR/.PLATFORM`. |
| `LEVEL` | Door-group weld datum, separate from the car's stopping height. |
| Scaler | Door leaf's `SCALE` part. Its X or Y dimension and the leaf suffix set travel. |
| `floor` / `trueFloor` | Indicated floor and tracked floor, respectively. Both can change during movement. |
| Move direction / queue direction | Travel direction and serving direction, respectively. Each uses `-1`, `0` and `1`. |
| Call key | The floor, direction and door group that identify a queue entry. Multiple sources can share it. |
| Call source | `"car"`, `"landing"` or `"api"` for passenger calls. ERSA and XCS submit `"api"` calls. |
| `API` | Server-local BindableEvent on each elevator for requests and state notifications. |
| Extension | Per-elevator server ModuleScript under `extensions`, initialized with the controller object. |
| ERSA | The group controller for shared hall stations. |
