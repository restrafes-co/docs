## ERSA group control

ERSA assigns shared hall calls to eligible cars. Each car runs its own Hera core and queue. Use a core that advertises `confirmsCalls` for explicit acceptance and cancellation callbacks.

### Set up a group

```text
GroupController
├── CONFIGURATION
├── Loader
├── ELEVATORS
│   ├── ElevatorA
│   └── ElevatorB
└── CALLBUTTONS
    └── 2
        └── .BUTTONS
            └── F
                └── U
                    └── BUTTON
```

Commission each complete car before moving it under `ELEVATORS`. Use the supplied ERSA loader and configuration. Match the station aliases to the car group IDs in the bank's `MISCELLANEOUS.DOOR_GROUP_ALIASES`. If the bank config supplies the legacy `DOOR_SIDE_ALIASES`, ERSA uses that table first. The example registers an Up call at floor 2 for alias `F`. Use `D` for Down or `N` for neutral. A direct part named `LED` carries the station lamp. With no `LED`, ERSA uses `BUTTON`.

### Test the shared calls

ERSA ranks eligible cars by service at the calling floor, compatible approach, then idle availability. It prefers the closer car within each rank. A rejected or cancelled assignment can fall through to another eligible car. ERSA submits source `"api"`, so use an API-scoped lock when testing reassignment.

Register a shared hall call and listen on the bank's `API` for `carAssigned` with `car`, `floor`, `direction` and `doorGroup`. Verify the station lamp clears at pickup. Repeat with one car in special service, then with a station served by only one car. If ERSA exhausts the eligible cars, it publishes `onMultibayError` with the call key and reason.

### Older accessory packages

Older cores can use the same callback for arrival and queue removal. For these cars, ERSA checks the queue and entrance state before clearing the station. For the legacy opening delay, ERSA reads `Settings.DOORS.OPEN_DELAY` from the car's `Settings` ModuleScript when present.

## Hall lanterns

A landing lantern uses the `indicator` event. The supplied lantern controller identifies the floor, entrance alias, and direction:

```text
Lanterns
└── 2
    └── F
        └── LANTERNS
            ├── U
            │   └── LED
            └── D
                └── LED
```

On the older supplied lantern controller, set `ELEVATOR_MODEL` to the car and `LANTERNS_MODEL` to the fixture container. That version reads the car aliases from a ModuleScript named `Settings`. Use a compatible accessory or subscribe directly to `indicator` if your car uses `CONFIGURATION`.

For a custom lantern, map `data.floor` and `data.doorGroup` to the fixture and `data.direction` to Up or Down. Apply `data.event` as `lit` or `unlit`.

Set timing in [Indicators and labels](/hera/configuration/indicators). For a terminal floor, fit only the direction light that can be used there, and test arrivals from the available direction.

## Floor displays

Add a `SurfaceGui` named `Display` below the elevator with a direct `TextLabel` named `FloorLabel`. Install this ModuleScript under `Elevator/extensions` on an extension-enabled core. It initializes the PI and updates it on `onFloorChanged`.

```lua
return {
    init = function(controller)
        local display = assert(controller.elevator.model:FindFirstChild("Display", true), "Display missing")
        local label = assert(display:FindFirstChild("FloorLabel"), "FloorLabel missing")
        label.Text = tostring(controller.elevator.getState().floor)
        controller.floor.onChanged(function(data)
            label.Text = if data.label then data.label.label else tostring(data.floor)
        end)
    end,
}
```

The snapshot supplies the numeric floor. Initialize from your floor-label mapping if the PI needs display text before the first floor-change event. A remote PI can subscribe through the [BindableEvent API](/hera/integration/controller-api).

## Choose the arrow meaning

| Event | Use when the arrow means |
| --- | --- |
| `onMoveDirectionChanged` | The car is physically travelling up or down. |
| `onQueueDirectionChanged` | The car will serve passengers in this direction next. |
| `indicator` | This landing's arrival lantern should be lit or unlit. |
| `indicatorCar` | The car's arrival direction lamp should be lit or unlit. |

A car that arrives while travelling up can next serve down. Test a final destination and a reversal so your arrows show the intended meaning.
