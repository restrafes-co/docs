## ERSA group control

ERSA assigns shared hall calls to eligible cars. Each car runs its own Hera core and queue, with acceptance and cancellation callbacks.

### Set up a group

```text
GroupController
├── CONFIGURATION
├── Loader
├── ELEVATORS
│   ├── ElevatorA
│   └── ElevatorB
└── CALLBUTTONS
    └── 2
        └── .BUTTONS
            └── F
                └── U
                    └── BUTTON
```

Move each complete car under `ELEVATORS`. Use the supplied ERSA loader and configuration. Match the station aliases to the car group IDs in the bank's `MISCELLANEOUS.DOOR_GROUP_ALIASES`. The example registers an Up call at floor 2 for alias `F`. Use `D` for Down or `N` for neutral. A direct part named `LED` carries the station lamp. With no `LED`, ERSA uses `BUTTON`.

### Call assignment

ERSA ranks eligible cars by service at the calling floor, compatible approach, then idle availability. It prefers the closer car within each rank. A rejected or cancelled assignment can fall through to another eligible car. ERSA submits source `"api"`.

The bank's `API` publishes `carAssigned` with `car`, `floor`, `direction` and `doorGroup`. The station lamp clears at pickup. If ERSA exhausts the eligible cars, it publishes `onMultibayError` with the call key and reason.

## Hall lanterns

A landing lantern uses the `indicator` event. The supplied lantern controller identifies the floor, entrance alias, and direction:

```text
Lanterns
└── 2
    └── F
        └── LANTERNS
            ├── U
            │   └── LED
            └── D
                └── LED
```

A lantern controller that reads car aliases from a ModuleScript named `Settings` uses `ELEVATOR_MODEL` for the car and `LANTERNS_MODEL` for the fixture container. If your car uses `CONFIGURATION`, use a compatible accessory or subscribe directly to `indicator`.

For a custom lantern, map `data.floor` and `data.doorGroup` to the fixture and `data.direction` to Up or Down. Apply `data.event` as `lit` or `unlit`.

Set timing in [Indicators and labels](/hera/configuration/indicators). For a terminal floor, fit only the direction light that can be used there.

## Floor displays

An extension can use `controller.floor.onChanged` to update a `TextLabel` when the floor indication changes. Read `data.label.label` when a label is available; otherwise, display the numeric `data.floor`. The initial state supplies the numeric floor, so use your floor-label mapping if the display needs a label before the first floor-change event. A remote PI can subscribe through the [BindableEvent API](/hera/integration/controller-api).

## Choose the arrow meaning

| Event | Use when the arrow means |
| --- | --- |
| `onMoveDirectionChanged` | The car is physically travelling up or down. |
| `onQueueDirectionChanged` | The car will serve passengers in this direction next. |
| `indicator` | This landing's arrival lantern should be lit or unlit. |
| `indicatorCar` | The car's arrival direction lamp should be lit or unlit. |

A car that arrives while travelling up can next serve down.
