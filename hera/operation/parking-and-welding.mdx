## Idle parking

Set `MISCELLANEOUS.PARKING.ENABLED = true`. `FLOOR` selects the parking landing and defaults to the startup floor. `REQUIRED_IDLE_TIME` is in seconds.

Hera queues parking with source `"parking"`, direction `0` and door group `0`. The car returns with the doors closed. A whole-floor or parking-source lock can prevent the trip. [Lock scopes](/hera/extensions/floor-lockouts#narrow-the-rule)

Test parking from another landing, then repeat with a passenger call during the idle interval.

## Passenger welding

`MISCELLANEOUS.WELD.PLAYERS_ENABLED` attaches detected avatars during travel. The detection area follows the cabin's `.PLATFORM` footprint. Set `UNWELD_TIME` to select the release phase.

| Value | Release point |
| --- | --- |
| `1` | Start of leveling |
| `2` | Full stop (default) |
| `3` | Pre-opening, or full stop when pre-opening does not run |

Recheck rider attachment across the platform after changing its footprint, the movement engine or the pre-opening settings.

## Loose objects

Hera forces `MISCELLANEOUS.WELD.OBJECTS_ENABLED` off during startup. Passenger welding has its own switch.
