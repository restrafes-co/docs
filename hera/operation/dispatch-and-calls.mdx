Hera keys each queue entry by `floor`, `direction` and `doorGroup`. Matching calls can share an entry across sources. At arrival, entries with the same floor and queue direction can open their respective entrances together.

## Which call is served next

Hera looks for the nearest compatible call ahead of the car. A late pickup must still be within the car's stopping envelope. If only opposing hall or API calls remain ahead, Hera can run to the furthest one as the reversal point. At a terminal with no remaining calls, the serving direction points back into the hoistway.

Use `currentMoveDirection` for travel and `currentQueueDirection` for serving direction. Both use the same values:

| Value | Direction |
| --- | --- |
| `-1` | Down |
| `0` | Neutral |
| `1` | Up |

## Repeated and current-floor calls

Repeating a registered car call keeps the entry. At a level, stationary car, a current-floor car call can open or reopen that entrance. A same-floor hall or API call is eligible for immediate service when the serving direction matches the request or the car's serving direction is neutral. During leveling, Hera can defer service until the car stops.

## Locks and cancellations

A [scoped lockout](/hera/extensions/floor-lockouts) removes matching callers from the queue. If an unlocked caller shares the entry, Hera can still serve the stop. With the car in motion, withdrawal can be pending through braking. Use the [call result and outcome](/hera/integration/controller-api#receive-completion-or-cancellation) to distinguish registration from service.

## Calls needing more boarding time

Pass `accessibility = true` on a scripted call to apply the [extended timers](/hera/configuration/doors#time-with-the-doors-open).

## Dispatch settings

`QUEUE.PROCESS_DELAY` defaults to one second. Hera rechecks the selected call, doors and car availability before starting. `QUEUE.RESET_DIRECTION_ON_FINAL_CAR_CALL` can return the serving direction to neutral after the final car call.

For dispatch under recall, Phase II or independent service, see [Service modes](/hera/operation/fire-and-independent-service).
