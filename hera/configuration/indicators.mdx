Hera publishes floor and direction changes for compatible indicators and hall lanterns.

## Floor labels

Use `API.FLOOR_LABELS` to replace numeric floor values with display text:

```lua
API = {
    FLOOR_LABELS = {
        [-1] = "B",
        [1] = "L",
        [2] = "2",
    },
}
```

The same labels can be shown on car-call fixtures that contain a `TextLabel` named `.LABEL`.

## Floor indication

`API.FLOOR.FLOOR_CHANGE_TIME` controls when the displayed floor changes during travel. Select the behavior that best matches the indicator style used in your model, then test it on both short and long trips.

`FLOOR_CHANGE_ON_ACCELERATION` controls whether the display may change while the car is accelerating.

## Hall lantern timing

The `API.INDICATOR` settings control when car and landing direction lamps turn on and off:

| Setting            | Controls                           |
| ------------------ | ---------------------------------- |
| `FLOOR_LIT_TIME`   | When a landing indicator turns on  |
| `FLOOR_UNLIT_TIME` | When a landing indicator turns off |
| `CAR_LIT_TIME`     | When a car indicator turns on      |
| `CAR_UNLIT_TIME`   | When a car indicator turns off     |

The matching `API.CHIME` settings control car and landing chime timing. Keep lantern and chime timing together so passengers receive a clear arrival signal.

See [Group control and displays](/hera/integration/group-control-and-displays) for connecting compatible accessories.
