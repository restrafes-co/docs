Open the elevator model in Explorer and double-click its `CONFIGURATION` ModuleScript. It returns a table containing sections such as `MOVE`, `DOORS`, and `SOUNDS`.

You can use the supplied configuration without writing new code. Change the values for the behavior you want, keeping setting names unchanged.

## Make your first change

To change the normal door-open time:

1. Stop the playtest.
2. Save a copy of the working configuration.
3. In `CONFIGURATION`, find the `DOORS` section.
4. Find `TIMER_LENGTH` and change its value, for example from `8` to `10`.
5. Start a new playtest, call the car, and check its wait before closing.

The value is in seconds. It does not change how long the panels take to move; opening and closing speeds are separate settings.

## Read setting paths

A path such as `MOVE.MOTOR_START_SETTINGS.UP_DELAY` means:

```lua
MOVE = {
    MOTOR_START_SETTINGS = {
        UP_DELAY = 0,
    },
},
```

The outer section is `MOVE`, the inner section is `MOTOR_START_SETTINGS`, and the setting is `UP_DELAY`.

Your configuration may use `["UP_DELAY"] = 0;` instead. That has the same meaning as `UP_DELAY = 0,` in these examples. Keep the style already used in your file if that is easier.

## Use examples without removing other settings

**Examples show only the settings being explained.** Edit those entries in the matching section of your existing configuration. Do not replace the whole ModuleScript with a partial example or add a second copy of an existing section.

For example, a `CUBIC_BEZIER = { ... }` example on the doors page belongs inside `DOORS`. A `CHIME = { ... }` sound example belongs inside `SOUNDS`. Each guide states the location before its example.

## Values you will see

| Value | Example | How to edit it |
| --- | --- | --- |
| Number | `TIMER_LENGTH = 8` | Use a number without quotes. Timers and delays are seconds unless stated otherwise. |
| Boolean | `ENABLED = true` | Use `true` or `false`, without quotes. |
| Text | `PRESET = "sample"` | Keep quotation marks around the text. |
| Automatic/default | `PRIMARY_FLOOR = nil` | `nil` leaves the setting unset; the guide describes the fallback. |
| Color | `Color3.fromRGB(255, 255, 255)` | Red, green, and blue values from 0 to 255. |
| Material | `Enum.Material.Neon` | A Roblox material value; preserve its spelling. |
| Numbered entry | `[1] = { LABEL = "L" }` | The bracketed number identifies a floor or door group. |

A missing comma, quote, or closing brace can prevent the ModuleScript from loading. Read the first syntax error in Output if Hera stops starting after an edit.

## Test a change

Change one behavior at a time, restart the playtest, and repeat the affected part of the [test guide](/hera/testing). Use a short trip and a long trip when changing movement; test opening, closing, and reopening when changing doors.

Some newer builds fill in omitted defaults and recognize older setting names. Keep your supplied configuration complete and use the current names on these pages when making new changes. The [settings reference](/hera/reference/configuration) includes supported older names.
