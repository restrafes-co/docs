Use `DOORS` for the car and landing operator profiles and their timing. Use the leaf's [`SCALE` and suffix](/hera/model-structure#door-leaves-and-travel-distance) to adjust stroke.

## Choose the movement method

| `DOORS.METHOD` | Movement method |
| --- | --- |
| `1` | Interpolation. |
| `2` | Built-in easing curve. |
| `3` | Separate cubic Bezier curves for opening and closing. |

## Car and landing timing

| Part of the cycle | Settings within `DOORS` |
| --- | --- |
| Open | `CAR_OPEN_SPEED`, `FLOOR_OPEN_SPEED` |
| Close | `CAR_CLOSE_SPEED`, `FLOOR_CLOSE_SPEED` |
| Close during nudging | `CAR_CLOSE_NUDGE_SPEED`, `FLOOR_CLOSE_NUDGE_SPEED` |
| Stagger a car or landing motor start | `CAR_OPEN_DELAY`, `FLOOR_OPEN_DELAY`, `CAR_CLOSE_DELAY`, `FLOOR_CLOSE_DELAY` |

<Note>
  For methods 2 and 3, smaller speed values give faster panel travel. Compare the car and landing panels together before tuning their delays.
</Note>

## Time with the doors open

`TIMER_LENGTH` sets normal dwell in seconds. `REOPEN_TIMER_LENGTH` sets dwell after a reopen and defaults to `TIMER_LENGTH`. For scripted calls with `accessibility = true`, set `ACCESSIBILITY_TIMER_LENGTH` and `ACCESSIBILITY_NUDGE_TIMER_LENGTH` at or above their normal counterparts. Hera applies the difference as an extension to the active timer.

## Opening and reversal delays

`OPEN_DELAY` delays normal arrival opening. `REOPEN_DELAY` and `RECLOSE_DELAY` control the wait when reversing direction. If pre-opening is enabled, check `MOVE.PREDOORS_IGNORE_DOOR_OPEN_DELAY` too.

## Obstruction sensors

`SENSOR_ENABLED` enables obstruction detection. The hold mode determines what happens to the normal timer:

| `DOORS.TIMER_HOLD_MODE` | On obstruction |
| --- | --- |
| `1` | Pauses the timer. |
| `2` | Resets the timer. |

[Door cycle and controls](/hera/operation/door-operation)

## Nudging

`NUDGE_TIMER_LENGTH` sets the nudge threshold. `NUDGE_CLOSE_DELAY` is the delay between that threshold and the close command. The warning sounds if `SOUNDS.NUDGE.ENABLED` is set.

## Custom opening and closing curves

Set `DOORS.METHOD = 3`, then edit `DOORS.CUBIC_BEZIER`:

```lua
CUBIC_BEZIER = {
    OPEN = { PLOTTING_POINTS = {0.65, 0, 0.35, 1} },
    CLOSE = { PLOTTING_POINTS = {0.65, 0, 0.35, 1} },
    REOPEN_CURVE_CORRECTION = true,
    INTERLOCK = {
        OPEN = { ENABLED = false, OFFSET = 0.05, DURATION = 0.12 },
        CLOSE = { ENABLED = false, OFFSET = 0.05, DURATION = 0.12 },
    },
    MOTOR_PITCH_SCALE_WITH_SPEED = false,
    MOTOR_PITCH_REFERENCE_SPEED = 0.8,
},
```

Each profile takes `{x1, y1, x2, y2}`, with each value in `[0, 1]`.

`REOPEN_CURVE_CORRECTION` adjusts the opening curve when reversing from a partly closed position.

The optional interlock stage adds short travel at the start of opening or end of closing. `OFFSET` sets the travel and `DURATION` is in seconds. Configure its audio in `SOUNDS.DOOR_INTERLOCK.OPEN` and `.CLOSE`.

`MOTOR_PITCH_SCALE_WITH_SPEED` changes method 3 motor audio with the selected cycle speed. `MOTOR_PITCH_REFERENCE_SPEED` is its reference value; it does not change panel travel.

## Sensor lights

`SENSOR_SIGNALIZATION` styles the entrance lights, including their state styles and transition times. The detection switch is `SENSOR_ENABLED`. [Door settings reference](/hera/reference/configuration#sensor-lights)
