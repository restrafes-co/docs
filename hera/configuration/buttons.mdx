Use a fixture model with a direct `BUTTON` BasePart. Hera derives the input from the fixture's name and its position in the panel hierarchy.

## Map front and rear entrances

The default `MISCELLANEOUS.DOOR_GROUP_ALIASES` maps `F = 1` and `R = 2`. Match the alias to your car and landing group IDs. [Model structure](/hera/model-structure)

## Car buttons

Under `CAR`, place fixtures inside a panel whose name starts with `.BUTTONS`. Use the alias followed by the numeric destination or control.

| Fixture | With `F = 1` and `R = 2` |
| --- | --- |
| `F1` or `F-1` | Front entrance at floor 1 or basement floor -1 |
| `R2` | Rear entrance at floor 2 |
| `FDO`, `FDC`, `FDH` | Front Door Open, Close and Hold |
| `ALARM` | Alarm while held |

Use the floor number in the fixture name. For floor `1`, name the fixture `F1` and add a descendant `TextLabel` named `.LABEL` to display a configured label such as `L`.

## Hall buttons

Under the landing, use `.BUTTONS/F/U/BUTTON` for a front Up call. Use `D` for Down or `N` for a neutral call. For shared stations, use the [ERSA layout](/hera/integration/group-control-and-displays#ersa-group-control).

## Button lights

Optional direct child parts whose names begin with `LED`, such as `LED` or `LED_Ring`, light together. If the fixture has no LED parts, Hera changes the appearance of `BUTTON`.

The `BUTTONS` configuration has four categories:

| Category | Fixtures |
| --- | --- |
| `CAR` | Car floor buttons. |
| `HALL` | Landing call buttons. |
| `DOOR_CONTROL` | Door Open, Close, and Hold. |
| `ALARM` | Alarm button. |

For example, edit the existing `BUTTONS.CAR` entries to change car-call lights:

```lua
CAR = {
    LIT_ON_CLICK_DURATION = 0.75,
    TRANSITION_DURATION = 0.1,
    UNLIT = {
        COLOR = Color3.fromRGB(236, 240, 255),
        MATERIAL = Enum.Material.SmoothPlastic,
    },
    LIT = {
        COLOR = Color3.fromRGB(236, 240, 255),
        MATERIAL = Enum.Material.Neon,
    },
},
```

`TRANSITION_DURATION` sets the color transition in seconds and defaults to `0.1`. Use `LIT_ON_CLICK_DURATION` for momentary feedback. Registered calls keep their lamp lit until service or cancellation.

<Note>
  The car's ordinary floor-button release timer reads `BUTTONS.HALL.LIT_ON_CLICK_DURATION`.
</Note>

A `TEXTURE` value in `LIT` or `UNLIT` changes a `Decal` or `Texture` named `.BUTTON` or `.TEXTURE` directly inside the illuminated part.

`LIT_ON_DOOR_MOVE` keeps Door Open and Door Close lamps lit during the corresponding strokes. [Lamp settings](/hera/reference/configuration#button-lights)

A flash indicates input feedback and can accompany a rejection. For a failure isolated to one entrance, check its alias, door group and any [lockout](/hera/extensions/floor-lockouts).
