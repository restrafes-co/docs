Hera uses fixture names to decide which floor, entrance, or door control a button operates. Every fixture model needs a direct child `BUTTON` part.

## Map front and rear entrances

Edit `MISCELLANEOUS.DOOR_GROUP_ALIASES`:

```lua
DOOR_GROUP_ALIASES = {
    F = 1,
    R = 2,
},
```

This maps `F` to door group `1` and `R` to group `2`. Each alias must point to a different group. Keep the alias consistent across car buttons, hall buttons, and accessories.

The model must contain the corresponding numeric door group. An alias does not create an entrance.

## Car buttons

Place a panel model directly under `CAR`. Its name must begin with `.BUTTONS`. Place the fixture models inside it.

| Fixture name | Function with the aliases above |
| --- | --- |
| `F1` | Call floor 1 using the front entrance. |
| `F-1` | Call floor -1 using the front entrance. |
| `R2` | Call floor 2 using the rear entrance. |
| `FDO` / `RDO` | Door Open for that entrance. |
| `FDC` / `RDC` | Door Close for that entrance. |
| `FDH` / `RDH` | Door Hold for that entrance. |
| `ALARM` | Sound the alarm while held. |

A front floor-2 button can look like this:

```text
CAR
└── .BUTTONS
    └── F2
        ├── BUTTON (BasePart)
        ├── LED (optional BasePart)
        └── SurfaceGui (optional)
            └── .LABEL (TextLabel, optional)
```

A floor button's number must exist in `FLOORS`, and its entrance must exist at that floor. Display labels do not change the button name: the button for a lobby numbered `1` stays `F1` even when its visible label is `L`.

Pressing an already registered destination does not cancel it. In normal service, pressing the current floor can open or reopen the selected entrance. See [Calls and dispatch](/hera/operation/dispatch-and-calls).

## Hall buttons

A hall panel belongs inside the landing's floor model. Under its `.BUTTONS` panel, add a model named for the entrance alias, then its direction fixtures:

```text
FLOORS
└── 2
    └── .BUTTONS
        └── F
            ├── U
            │   └── BUTTON
            └── D
                └── BUTTON
```

| Name | Request |
| --- | --- |
| `U` | Travel up from this floor. |
| `D` | Travel down from this floor. |
| `N` | Call without a preferred direction. |

The lowest landing normally needs Up and the highest needs Down. Use both at intermediate landings. For a rear panel, put the direction fixtures inside `R` instead of `F`.

## Button lights

Optional direct child parts whose names begin with `LED`, such as `LED` or `LED_Ring`, light together. If the fixture has no LED parts, Hera changes the appearance of `BUTTON`.

The `BUTTONS` configuration has four categories:

| Category | Fixtures |
| --- | --- |
| `CAR` | Car floor buttons. |
| `HALL` | Landing call buttons. |
| `DOOR_CONTROL` | Door Open, Close, and Hold. |
| `ALARM` | Alarm button. |

For example, edit the existing `BUTTONS.CAR` entries to change car-call lights:

```lua
CAR = {
    LIT_ON_CLICK_DURATION = 0.75,
    TRANSITION_DURATION = 0.1,
    UNLIT = {
        COLOR = Color3.fromRGB(236, 240, 255),
        MATERIAL = Enum.Material.SmoothPlastic,
    },
    LIT = {
        COLOR = Color3.fromRGB(236, 240, 255),
        MATERIAL = Enum.Material.Neon,
    },
},
```

`TRANSITION_DURATION` is the color-change time in seconds; when omitted, Hera uses `0.1`. `LIT_ON_CLICK_DURATION` controls brief press feedback when a call does not remain registered. Registered call lamps stay lit until the call is served or removed.

A `TEXTURE` value in `LIT` or `UNLIT` changes a `Decal` or `Texture` named `.BUTTON` or `.TEXTURE` directly inside the illuminated part. Keep the supplied texture structure when changing this feature.

`LIT_ON_DOOR_MOVE` keeps door-control lights active during movement. Older configuration files also contain `LIT_ON_CLICK`, `LIT_ON_HOLD`, and `LIT_ON_HALL_LOCK`; these switches are retained but do not change the current 26.9.6 input lighting. See [Settings reference](/hera/reference/configuration#button-lights).

## Labels and sound

To put `L`, `B`, or another label on a car button, configure [floor labels](/hera/configuration/indicators#floor-labels) and include a `TextLabel` named `.LABEL` in that fixture.

Button press sounds are controlled separately by `SOUNDS.ON_BUTTON_PRESS`. Separate rejection sounds are available for locked car and hall calls. See [Sound and voice](/hera/configuration/sound-and-voice).

## Check your panel

Test every floor and direction, watch the lamp after arrival, and try a current-floor call. If nothing happens, first check the `BUTTON` part, fixture name, alias, and served entrance. Special service changes what the controls do; see [Fire service](/hera/operation/fire-service) and [Independent service](/hera/operation/independent-service).
