Connect your AI assistant to XCS to manage locations, access points, access groups and schedules, review activity, and remotely unlock doors.

Add this MCP server URL in your assistant's connection settings:

```text
https://api.restrafes.co/api/xcs/mcp
```

MCP is available with **XCS Pro**. Your assistant uses your existing organization permissions.

Try asking:

- “Show the access points in my Lobby location.”
- “Create an access point called North Entrance.”
- “Show recent denied access events.”
