Your assistant discovers these 31 tools automatically. Available actions follow the access you approved and your organization permissions.

## Organizations

| Tool                     | Action                    |
| ------------------------ | ------------------------- |
| `my_organizations`       | List your organizations   |
| `get_organization`       | View an organization      |
| `my_organization_limits` | Check organization limits |

## Locations

| Tool              | Action                                  |
| ----------------- | --------------------------------------- |
| `my_locations`    | List locations                          |
| `get_location`    | View a location                         |
| `create_location` | Create a location                       |
| `update_location` | Edit a location                         |
| `delete_location` | Delete a location and its access points |

## Access points

| Tool                                | Action                                                   |
| ----------------------------------- | -------------------------------------------------------- |
| `my_access_points`                  | List access points                                       |
| `get_access_points`                 | View access points in bulk                               |
| `create_access_points`              | Create access points in bulk                             |
| `update_access_points`              | Edit access points in bulk                               |
| `delete_access_point`               | Delete an access point                                   |
| `update_access_point_configuration` | Change active state, offline behavior or unlock duration |
| `set_access_point_armed`            | Arm, disarm or schedule an access point                  |

## Access groups

| Tool                  | Action                 |

| `create_access_group` | Create an access group |

## Schedules
